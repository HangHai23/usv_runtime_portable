1. ONNX Runtime CPU后端，显式letterbox/NMS/原图框还原；不需要Torch或Ultralytics，也不下载模型。
2. Nano Ubuntu 18.04宿主→Ubuntu 22.04/Humble ARM64容器，固定CPU依赖版本。
3. 默认dry_run、容器运动开关、设备白名单映射、宿主日志持久化，不用privileged或NVIDIA GPU库注入。
